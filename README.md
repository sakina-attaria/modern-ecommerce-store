# ShopEase — Modern E-Commerce Website

A fully responsive, modern e-commerce website built with HTML5, CSS3, and vanilla JavaScript. Users can browse products, filter/search/sort, view product details, manage a shopping cart, and complete checkout — all with data persisted in LocalStorage.

## ✨ Features
- Responsive navbar with mobile menu and search
- Home page with hero banner, categories, featured products, offers, testimonials, newsletter
- Products page with search, category filter, price filter, and sorting
- Product details page with quantity selector and related products
- Shopping cart with add/remove/update quantity, persisted via LocalStorage
- Checkout form with validation and order summary
- Order confirmation page with unique order number
- Toast notifications
- Fully mobile-responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Vanilla, ES6)
- LocalStorage API
- Git & GitHub
- GitHub Pages (deployment)
